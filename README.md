# مِرصاد — المراقبة والتنبيهات (v0.5)

يرسل لك على تيليجرام، **تلقائياً ودون أي إدخال منك**:
1. **تقرير قبل افتتاح السوق*name: mirsad

on:
  schedule:
    - cron: "0 12 * * 1-5"      # قبل الافتتاح: 12:00 UTC = 3:00 ظهراً بتوقيت بغداد
    - cron: "*/15 * * * 1-5"    # مراقبة: صدور البيانات والحركات المفاجئة
    - cron: "0 9 * * 6"         # ملخص معايرة أسبوعي: السبت 12:00 ظهراً بتوقيت بغداد
  workflow_dispatch:
    inputs:
      mode:
        description: "test (اختبار فوري) | preopen | auto | calibrate | backtest (اختبار تاريخي 5 سنوات)"
        default: "test"

permissions:
  contents: write

concurrency:
  group: mirsad
  cancel-in-progress: false

jobs:
  run:
    runs-on: ubuntu-latest
    timeout-minutes: 25
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: pip

      - name: تثبيت المتطلبات
        run: pip install -r requirements.txt

      - name: تشغيل مِرصاد
        env:
          TELEGRAM_TOKEN: ${{ secrets.TELEGRAM_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
          FRED_API_KEY: ${{ secrets.FRED_API_KEY }}
          EVENT_NAME: ${{ github.event_name }}
          SCHEDULE: ${{ github.event.schedule }}
          INPUT_MODE: ${{ github.event.inputs.mode }}
        run: |
          if [ "$EVENT_NAME" = "schedule" ]; then
            if [ "$SCHEDULE" = "0 12 * * 1-5" ]; then MODE=preopen
            elif [ "$SCHEDULE" = "0 9 * * 6" ]; then MODE=calibrate
            else MODE=auto; fi
          else
            MODE="${INPUT_MODE:-test}"
          fi
          echo "الوضع: $MODE"
          python runner.py --mode "$MODE"

      - name: حفظ الحالة والسجل
        if: always()
        run: |
          git config user.name "mirsad-bot"
          git config user.email "mirsad-bot@users.noreply.github.com"
          for f in state.json history.csv backtest.json; do [ -f "$f" ] && git add "$f"; done
          git diff --cached --quiet || (git commit -m "تحديث حالة مِرصاد" && git push)
* — 3:00 ظهراً بتوقيت بغداد (أيام الأسبوع).
2. **تنبيه بعد صدور البيانات الكبرى** (فائدة، وظائف، تضخم...) مع المقارنة بالمتوقع.

**ما أُضيف في v0.6:** مخطط النقاط (Dot Plot) داخل قاعدة تايلور (r* من النقاط)، والعجز المالي كنسبة من الناتج (12 شهراً)، والسيولة الصافية، و**سياق المزايدة (Auction)**: القيمة السابقة وجلسة الليل والفجوة والمدى المتوقع من VIX وميل يومي تجريبي «غير مثبت». وضع `backtest` يختبر الدرجة تاريخياً بلا نظر للمستقبل ويقارنها بـ VIX وحده.

**كتل معلوماتية لا تدخل الدرجة:** منحنى العائد 2-10، تمركز المضاربين الكبار (COT)، حركة السبعة الكبار والبنوك الكبرى، الارتباطات، مواعيد الأرباح، خطابات الفيدرالي، وعناوين أخبار (توقعات البنوك، الشركات الكبرى، السياسة المالية والتجارية) **دون تفسير**، وعمر البيانات.

## الإعداد (مرة واحدة، نحو 15 دقيقة)

### أ) بوت تيليجرام
1. افتح تيليجرام وابحث عن **@BotFather** ← أرسل `/newbot` ← اختر اسماً ← سيعطيك **توكن** (نص طويل). احفظه.
2. افتح البوت الجديد وأرسل له كلمة `hi`.
3. افتح في المتصفح (استبدل TOKEN بتوكنك): `https://api.telegram.org/botTOKEN/getUpdates`
   ستجد `"chat":{"id":123456789` — هذا **رقم محادثتك**.

### ب) GitHub
1. أنشئ حساباً مجانياً في github.com.
2. **New repository** ← سمّه `mirsad` ← **Public** (يجعل التشغيل مجانياً دون حدود) ← Create. التوكن لن يُنشر، سنحفظه كـ«سر».
3. اضغط **uploading an existing file** وارفع **كل محتويات** هذا المجلد، بما فيها مجلد `.github`.
   إن لم يقبل المتصفح رفع المجلد المخفي `.github`: من المستودع اختر **Add file ← Create new file**،
   واكتب في خانة الاسم بالضبط `.github/workflows/mirsad.yml`، ثم الصق محتوى الملف **`workflow-mirsad.yml`** المرفق، واضغط Commit.
4. اضغط **Commit changes**.

### ج) الأسرار
**Settings ← Secrets and variables ← Actions ← New repository secret**، وأضف:
- `TELEGRAM_TOKEN` = توكن البوت
- `TELEGRAM_CHAT_ID` = رقم محادثتك

### د) الاختبار الحقيقي
تبويب **Actions** ← **mirsad** ← **Run workflow** (الوضع `test`). خلال دقيقة أو دقيقتين تصلك رسالة اختبار ثم تقرير ببيانات حقيقية.
وإن تعذّر مصدر ما فستجد سطر «⚠» في التقرير يقول أيّها، دون أن يتوقف التقرير.

> **المستقبل:** خطة النسخة الاحترافية (بيانات لحظية + ذكاء اصطناعي للأخبار الجيوسياسية + بنود مدفوعة) في ملف `ROADMAP.md`.
> البنية جاهزة لها: كل بند مدفوع له وزن محجوز يدخل الحساب تلقائياً عند توفر مزوّد.

## ما لا يغطيه (بصراحة)
- **تمركز الخيارات (Gamma/GEX):** لا مصدر مجاني موثوق. تُرصد أيام انتهاء الخيارات بالتقويم فقط.
- **تقارير البنوك الكاملة وتوقعاتها:** مدفوعة. تصلك عناوين الأخبار عنها فقط، ولا تدخل الدرجة.
- **توقعات الفائدة (CME FedWatch):** لا واجهة مجانية رسمية. يُستعاض عنها بحركة عائد السنتين.
- **استطلاعات المعنويات** (مؤشر الخوف والطمع، AAII): غير مضمّنة.
- **فهم الأخبار وتفسير أثرها:** التصنيف بالقواعد يكشف ويقيس لكنه لا يفهم السياق (نفي، سخرية، حدث غير مسبوق) ولا يحدد اتجاه الأثر؛ ذلك يحتاج نموذجاً لغوياً (مرحلة لاحقة). قوائم الكلمات وأوزانها تقديرية وتُضبط بعد التشغيل.
- **اتجاه السوق (صاعد/هابط):** لا يحسبه؛ المخاطرة فقط. والمستويات الفنية متروكة لتحليلك.

## مصادر لم يُتحقق منها فعلياً (قد تحتاج إصلاحاً عند أول تشغيل)
- رموز Yahoo الأقل شيوعاً: `^VIX3M` و`^MOVE` و`^IRX`، وشكل عرض عائد 10 سنوات.
- صيغة ملف COT من CFTC (يُتحقق من منطقية الأرقام؛ وإلا يُستبعد مع تحذير).
- مواعيد الأرباح عبر yfinance (غير رسمي).
- حقل «الفعلي» في خلاصة التقويم عند الصدور؛ إن لم يُملأ فلن تصلك تنبيهات «بعد الصدور».
- FRED عبر رابط CSV المباشر دون مفتاح.

أي مصدر يفشل **يُستبعد مكوّنه من الحساب** وتُعاد معايرة الأوزان على ما تبقى، مع تحذير ظاهر.

## حدود مهمة
- **الأوزان تقديرية:** الأحداث الكبرى مبنية على دراسات صغيرة العينة، وبقية المكوّنات الجديدة بتقدير أولي. **سجل الأداء** (`history.csv`) يتراكم تلقائياً، وبعد 3–4 أسابيع يظهر في الملخص الأسبوعي هل الدرجات تعكس الحركة الفعلية، وعندها تُضبط الأوزان.
- **الجدولة على GitHub ليست لحظية:** قد تتأخر التنبيهات 5–20 دقيقة وقت الازدحام وقد تُتخطى دورة أحياناً.
- **التقرير 3:00 بغداد** يسبق افتتاح السوق الأمريكي (4:30 عصراً حتى 1 نوفمبر، ثم 5:30 عصراً).
- **الأسعار مجانية وغير رسمية** (Yahoo): قد تحجب خوادم GitHub أحياناً وقد تتأخر.
- **الحدث المفاجئ** يُرصد من حركة الأسواق وعناوين الأخبار، لا من «فهم» الخبر.
- تقويم العطل مكتوب لعام 2026 ويُحدَّث سنوياً.
- جدولة GitHub قد تتوقف إن بقي المستودع دون نشاط 60 يوماً؛ يُعاد تفعيلها من تبويب Actions.
- إشارات إحصائية لأغراض التجربة، وليست توصية استثمارية.

## المنظومة الكلية (macro.py)
- **الفكرة:** لا تُقرأ الأرقام منفردة؛ تُدمج في ميل عام للفدرالي (متشدد/متساهل/متوازن) مع درجة ثقة وكشف «التعارض» (تضخم مرتفع مع بطالة صاعدة).
- **تسعير السوق للفائدة:** فرق عوائد 3 و6 أشهر وسنة عن الفائدة الفعلية، **تقدير تقريبي بهامش 10–15 نقطة أساس وليس بديلاً عن CME FedWatch**.
- **افتراضات قابلة للتعديل في أعلى الملف:** الحياد الحقيقي r*=1.0 والبطالة الطبيعية u*=4.2 وهدف التضخم 2%.
- **مواعيد الاجتماعات 2026** من تقويم federalreserve.gov (تُحدَّث سنوياً).
- بيانات التضخم والعمل شهرية فتصل متأخرة أسابيع؛ الأوزان تُعايَر لاحقاً بسجل الأداء.
- لا يقرأ نبرة بيانات الفدرالي وخطابات أعضائه بعد (مرحلة قادمة محتملة بالقواعد إن توفر النص).
