- **الإصدارات الموثقة تدخل التقييم** (`release_impact.py`): Actual مقابل Forecast وPrevious والمراجعات، بوزن حسب الأهمية والسياق، بلا عدّ مزدوج مع التضخم والفيدرالي، و«تقييم أولي — تأكيد السوق غير متاح بعد» إلى أن يصل تأكيد السوق أو رفضه. CPI مرتفع لا يعني هبوطاً تلقائياً. بلا إصدار موثق: «لم يُدمج الإصدار بعد».
- **تحديث مهم**: بطاقة أعلى الصفحة تبقى حتى «اطّلعت» أو فتح التفاصيل، حالة القراءة محفوظة في المتصفح، معرّف ثابت يفتحه الإشعار (`#e=<id>`)، وسجل أحداث واحد يغذي تيليجرام والواجهة (`state.alerts`) لكل أنواع التنبيهات (حركة، صدمة، صدور، وصول متأخر، مراجعة).
- **الموبايل**: تحديث غير مقروء ← التقرير ← الخبر القادم ← «نبض الأسواق» (بطاقة لكل مؤشر، لون = أثر ES، سهم = حركة المؤشر) ← زر التفاصيل والسجل.
- **الكمبيوتر**: جدول أخبار (Actual/Forecast/Previous/Revision/Surprise/المصدر)، تلوين خلفية اختياري، وضع مراقبة عن بعد بخط كبير وملء الشاشة، وجرس اختياري (تشغيل/كتم/اختبار/حفظ التفضيل، بلا رنين عند أول تحميل ولا تكرار).
- **إصلاحات v0.18.1 المكتملة**: GDP لا يُنسب لمرحلة (Advance/Second/Third) إلا بدليل نسخة الإصدار (vintage)؛ المراجعة تحدّث القيمة والمصدر والحساب وprev_revised معاً وتُسترجع بعد إعادة التشغيل؛ نسخة الترحيل تُحفظ في `backups/` داخل المستودع (`python migrate.py rollback`)؛ الانتظار السريع يستبعد الأحداث غير المدعومة ويُرسل المتحقَّق فوراً ويحترم الحصص؛ رسالة فشل التحميل تطابق السلوك (لا بيانات تجريبية تلقائياً) ويُحتفظ بآخر لقطة صالحة.
- **الاختبارات**: `pip install -r requirements-dev.txt` ثم `python tests_<الاسم>.py`. اختبار المتصفح: `python tests_browser.py shots`.

**حدود صريحة:** نجاح المحاكاة ليس دليلاً على الجلب الحي (BLS/FRED/Yahoo محجوبة في بيئة التطوير؛ تحقق عبر `actuals-check`). الجرس يعمل والصفحة مفتوحة فقط، وتيليجرام هو التنبيه المضمون. أوزان الأثر تقديرية وغير معايَرة.

## الواجهة المرئية (GitHub Pages)
بعد كل تقرير قبل الافتتاح (وفي وضع `test`) يكتب البرنامج `docs/data.json` وينشر مجلد `docs` تلقائياً على صفحة مجانية، ويضع رابطها في آخر رسالة تيليجرام. الصفحة نفسها واجهة مِرصاد (مقياس المخاطرة، سياق المزاد، المنظومة والفدرالي، التفاصيل) بالأرقام الحقيقية، وتبدّل بين العربية والإنجليزية (نص التقرير يبقى بالعربية).
**تفعيلها مرة واحدة:** المستودع ← Settings ← Pages ← Source: **GitHub Actions**. ثم شغّل `test`. الرابط: `https://اسم-حسابك.github.io/mirsad/`.
الصفحة عامة لمن يعرف الرابط (بطبيعة Pages المجانية)، وتحوي أرقام السوق ولا تحوي أي أسرار.

## الإعداد (مرة واحدة، نحو 15 دقيقة)

### أ) بوت تيليجرام
1. افتح تيليجرام وابحث عن **@BotFather** ← أرسل `/newbot` ← اختر اسماً ← سيعطيك **توكن** (نص طويل). احفظه.
2. افتح البوت الجديد وأرسل له كلمة `hi`.
3. افتح في المتصفح (استبدل TOKEN بتوكنك): `https://api.telegram.org/botTOKEN/getUpdates`
   ستجد `"chat":{"id":123456789` — هذا **رقم محادثتك**.

### ب) GitHub
1. أنشئ حساباً مجانياً في github.com.
2. **New repository** ← سمّه `mirsad` ← **Public** (يجعل التشغيل مجانياً دون حدود) ← Create. التوكن لن يُنشر، سنحفظه كـ«سر».
3. اضغط **uploading an existing file** وارفع **كل محتويات** هذا المجلد، بما فيها مجلد `.github`.
   إن لم يقبل المتصفح رفع المجلد المخفي `.github`: من المستودع اختر **Add file ← Create new file**،
   واكتب في خانة الاسم بالضبط `.github/workflows/mirsad.yml`، ثم الصق محتوى الملف **`workflow-mirsad.yml`** المرفق، واضغط Commit.
4. اضغط **Commit changes**.

### ج) الأسرار
**Settings ← Secrets and variables ← Actions ← New repository secret**، وأضف:
- `TELEGRAM_TOKEN` = توكن البوت
- `TELEGRAM_CHAT_ID` = رقم محادثتك

### د) الاختبار الحقيقي
تبويب **Actions** ← **mirsad** ← **Run workflow** (الوضع `test`). خلال دقيقة أو دقيقتين تصلك رسالة اختبار ثم تقرير ببيانات حقيقية.
وإن تعذّر مصدر ما فستجد سطر «⚠» في التقرير يقول أيّها، دون أن يتوقف التقرير.

> **المستقبل:** خطة النسخة الاحترافية (بيانات لحظية + ذكاء اصطناعي للأخبار الجيوسياسية + بنود مدفوعة) في ملف `ROADMAP.md`.
> البنية جاهزة لها: كل بند مدفوع له وزن محجوز يدخل الحساب تلقائياً عند توفر مزوّد.

## ما لا يغطيه (بصراحة)
- **تمركز الخيارات (Gamma/GEX):** لا مصدر مجاني موثوق. تُرصد أيام انتهاء الخيارات بالتقويم فقط.
- **تقارير البنوك الكاملة وتوقعاتها:** مدفوعة. تصلك عناوين الأخبار عنها فقط، ولا تدخل الدرجة.
- **توقعات الفائدة (CME FedWatch):** لا واجهة مجانية رسمية. يُستعاض عنها بحركة عائد السنتين.
- **استطلاعات المعنويات** (مؤشر الخوف والطمع، AAII): غير مضمّنة.
- **فهم الأخبار وتفسير أثرها:** التصنيف بالقواعد يكشف ويقيس لكنه لا يفهم السياق (نفي، سخرية، حدث غير مسبوق) ولا يحدد اتجاه الأثر؛ ذلك يحتاج نموذجاً لغوياً (مرحلة لاحقة). قوائم الكلمات وأوزانها تقديرية وتُضبط بعد التشغيل.
- **اتجاه السوق (صاعد/هابط):** لا يحسبه؛ المخاطرة فقط. والمستويات الفنية متروكة لتحليلك.
